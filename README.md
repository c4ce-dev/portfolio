# Christopher Force — Professional Site

Personal website for [christopherforce.com](https://christopherforce.com), focused on web application development, automation, and AI-assisted software work.

## Stack

- HTML
- SCSS
- Bootstrap
- Parcel
- ScrollReveal

## Local development

```bash
npm install
npm start
```

Parcel will start the local development server (typically at `http://localhost:1234`).

## Production build

```bash
npm run build
```

The compiled site is written to `dist/`.

## Deployment

The site is suitable for deployment to Netlify, Vercel static hosting, or any host that can serve the Parcel output.
